# ChatGPT UI Clone

A frontend clone of the ChatGPT interface built using **HTML and CSS**. The project recreates the dark-themed ChatGPT layout with a sidebar, navigation, chat input, buttons, icons, and hover effects.

## 🚀 Live Preview

[**View Live Demo →**](http://aradhya.lusa.co.in/CSS-Project-ChatGPT-CLone/)

## ✨ Features

- ChatGPT-inspired dark UI
- Sidebar with navigation links
- Chat and Work navigation
- Styled chat input area
- Think, microphone, and voice buttons
- Hover effects and interactive UI elements
- Font Awesome icons

## 🛠️ Technologies

- HTML5
- CSS3
- Font Awesome

## 📌 Note

This project is a **frontend UI clone for learning and practice**. It does not include actual ChatGPT or AI functionality.

**⚠️ The current version is not responsive and is designed primarily for desktop screens.**
